# Bot 模式

> 尚未发布：本文描述当前源码行为，正式版本不含此功能。限制见[当前限制](#当前限制)。

Bot 是有名字、样子和性格的私人助理。每个 Bot 有一个“主聊天”：像同一个人一直和你聊，不显示项目、线程、模型名或上下文压缩。Pi Agent 页面和助手对话页面保持原样，继续面向需要完整工作台控制的使用方式。

每个 Bot 本质上是一个[助手档案](AGENT_PROFILES.md)，有自己的“关于你”、长期记忆、技能、模型和工作目录。不同 Bot 之间互不共享这些内容。

## 开始

服务端支持时，导航栏出现“Bot”。还没有 Bot 时显示欢迎页，点“开始”创建第一个 Bot 并进入它的主聊天。

Bot 需要聊天模型才能说话。没有任何可用聊天模型时，欢迎页和问候里出现“接入模型”，打开“供应商与模型”设置；接入并刷新模型目录后，Bot 页面重新检查，出现“开始”。只要有可用模型，就不需要额外选择：Bot 跟随工作台的默认模型，也可以在它的设置里单独指定。

## 互相认识

第一次打开主聊天时，Bot 在本地打招呼，这一步不调用模型：

- **好呀**：开始两三分钟的访谈：怎么称呼你、主要帮你做什么、它的名字和头像、性格，以及一两个关于你的轻问题。每一项由 Bot 在输入框上方提出设置卡，你可以直接修改，选“保存”才生效，“先不改”则不保存。最后 Bot 会说明它的做事方式，并给出几件马上能做的事。
- **先跳过**：直接开始聊天，名字和性格以后随时可以在设置里改。

访谈进度保存在 Bot 设置中，刷新、换设备或隔几天再回来都能接着聊。设置卡只能由当前 Bot 页面保存：服务端核对这张卡仍在该 Bot 主聊天的当前会话中等待回答、只接受卡上提出过的字段，再按档案修订保存；在其他客户端选择“保存”不会写入任何设置。

### 第二个及以后的 Bot

新 Bot 先列出其他 Bot 已记下的“关于你”条目，默认全部勾选。取消不想让它知道的条目后选“记住这 N 条”，或选“不用，重新认识”。有多个 Bot 时可以切换来源。只复制勾选且来源中仍存在的条目，已有条目不会重复；访谈随后不再问这些内容已经回答的问题。

复制是一次性的。之后每个 Bot 的“关于你”各自保存，在一个 Bot 中更新不会同步到其他 Bot。

## 主聊天

主聊天里回复带有 Bot 的头像和名字（生成过程中也是），输入框提示“给 {名字} 发消息”。工作台的项目、模型、上下文和运行控制在 Bot 页面中隐藏；需要这些控制时使用 Pi Agent 页面。

回复前做过的事收在一行“用时 · N 个步骤”里，点开可回看；这一轮往[我记着的事](#我记着的事)里记了东西时，这一行还会写“记下 N 件事”，对应步骤显示为“记下了 · 内容”，翻找更早的聊天显示为“翻找之前的聊天 · 关键词”。进行中显示“正在思考”“正在处理”，需要你确认时显示“等你确认”。Bot 记住的事以“{名字} 记下了”显示在对应消息下，可撤销、标为不对或编辑。工作台的记忆回执栏和“本轮文件”编辑记录不在 Bot 页面显示。Bot 交给你的文件显示为文件卡，点文件名在右侧（手机为全屏面板）预览，右侧下载按钮下载原文件。

Bot 的回复和普通 Pi Agent 一样可以读写文件、执行命令、上网和使用已配置的工具。它创建的文件默认放在自己的工作目录：`<位置>/PivaneBots/bot-<ID 前 8 位>/`，目录中的 README 说明归属；改名不移动目录。位置是家目录（在允许的项目根内时），否则是第一个项目根；不会放在 Pivane 服务的运行目录或安装目录里。

### 长期聊天的维护

主聊天可以一直用下去，工作台在后台按下面的顺序维护它，不需要操作，也不在页面上提示：

1. **省略旧的工具输出**：上下文用到窗口的 35% 以上、且一次能省下至少 1 万 token 和当前上下文的 20% 时，在回复结束后把最近 3 次发言之前、4000 字以上的工具输出换成一行说明（Bot 需要时可以重新查看）。“我记着的事”的记录和设置卡不会被省略。
2. **空闲时整理摘要**：回复结束后隔了一段时间（至少 10 分钟，模型提示缓存更久时等到缓存过期）仍没有新消息，上下文用到 55% 以上、且 Pi 原样保留的最近部分之前还有足够多（至少 2 万 token 和窗口的 20%）可以整理时，在后台整理一次摘要，下一条消息不用等它。窗口快满时 Pi 自己的自动压缩仍然生效，摘要方式相同。
3. **结构化摘要**：摘要用这个 Bot 的模型和思考程度，写成“在聊什么 / 经过 / 现在进行到哪”，并同步[我记着的事](#我记着的事)。摘要失败时改用 Pi 原生的摘要，下一次回复前 Bot 会重新看到完整的“我记着的事”。
4. **换代**：当前会话文件达到 8 MiB、8000 条记录或 60 天时，接续到新的原生会话文件。换代总是紧接在一次摘要之后（通常在空闲整理时一并进行），这次摘要还会核对 Pi 原样保留的最近部分，使“我记着的事”在换代前同步；内容太少、没有可整理部分的会话暂不换代。新会话开头带有不显示的交接内容：“我记着的事”、最近的摘要、摘要之后的原话（最多 64000 字，不含工具输出）、模型和思考程度。

Bot 回答涉及更早内容时，可以在这个聊天的所有代里翻找原话（“翻找之前的聊天”），并查看某条消息前后的原文；它只读这些会话文件，结果会说明搜到了哪些部分。

### 更早的聊天

换代之前的内容显示在当前聊天上方，标为“更早的聊天 · 日期范围”，点开后逐段只读回看，“再往前看”继续展开更早一段；没有任何对话的一代自动跳过。这些内容从服务器读取原生会话文件，不启动旧会话的运行实例。

页面断线重连或换代时，Bot 页面总是重新确认主聊天当前所在的会话再连接，不会回到已经换下的旧会话。

当前会话发生过上下文压缩时，Bot 页面不显示压缩提示，压缩前的内容同样标为“更早的聊天”。

换代保留每一代完整的原生会话文件。换代过程中断时，下次打开主聊天前工作台先按原生证据恢复：只有新会话完整写入、并能证明接在旧会话最后一条记录之后时才采用，否则继续使用原会话，不会重放已经发生的对话。

### 在其他页面中

Bot 的原生会话仍会出现在 Pi Agent 页面的 `PivaneBots/bot-…` 项目下，可以按普通线程查看。它们不能移动到其他项目，也暂时不能绑定微信（见[当前限制](#当前限制)）。“助手对话”页面不列出 Bot 身份；打开指向 Bot 身份的助手对话链接时转到该 Bot 的主聊天。有 Bot 功能时，手机底栏不再显示“助手对话”，从“更多功能”进入；电脑侧栏中它排在“多媒体实验室”之后。

## 我记着的事

“我记着的事”是这个聊天的记事本，记下你定下的事、答应的事（谁答应、截止哪天）、还在等答案的问题、这段聊天的偏好和要求，以及要记牢的名字、编号、数字和日期。它只属于当前聊天；跨聊天的“关于你”见设置里的“记忆和关于你”。

- Bot 在聊天中随时记下和更新；整理摘要时还会对照原话补记和同步，例如你说过“不用了”的事会标为不需要。补记必须引用原话：“已经定下的”和“偏好和要求”只认你说过的话，Bot 的建议在你接受之前不算定了。
- 电脑在 Bot 列表底部（“{名字} 的设置”上方）打开，手机点顶部右侧的图钉，或在左上角菜单中打开。
- 按“答应的事、等回答的问题、已经定下的、偏好和要求、要记牢的信息”分组。答应的事和等回答的问题左侧有圆圈，点一下标为完成（已有答案）。每条可以修改内容（答应的事还能改截止日期）、标为“不需要了”或删除；删除前会再确认一次，删掉后 Bot 不再记得。已完成、不需要了和被新内容取代的事收在底部，可以重新打开。
- 点“出处”显示这条来自哪句话（你说的、Bot 说的或查到的内容），换代后仍然保留。
- 修改在聊天空闲时保存；Bot 正在回复时会提示稍后再改。其他设备或 Bot 刚刚改过时，列表自动刷新并提示再试一次。你的修改会在下一次回复前告诉 Bot。

## 设置

点击 Bot 列表底部的“{名字} 的设置”（手机在左上角菜单中）。设置窗口包括：

| 项目 | 说明 |
|---|---|
| 名字和样子 | 名字（最多 40 字）和表情头像。图片头像在身份页上传 |
| 主要帮你做什么 | 一句话说明，Bot 会以此为主要职责 |
| 性格 | Bot 的说话方式与个性（SOUL），下一条回复起生效 |
| 用哪个模型 | “跟随默认”或指定模型及思考程度，只影响这个 Bot；所选模型暂时不可用时保留设置并继续使用当前模型 |
| 做事方式 | 放手（默认）、稳妥、每次都问，见下文 |
| 更多 | “记忆和关于你”打开该 Bot 身份页的“关于你”；“重新互相认识”回到主聊天重新访谈 |

只保存改动过的字段。设置在别处刚被修改时，窗口重新读取最新设置并保留你的修改，提示检查后再保存一次。未保存就关闭时会先提醒一次。

### 做事方式

| 方式 | Bot 直接做的事 | 先问你的事 |
|---|---|---|
| 放手（默认） | 读文件、上网、记忆、提醒、图片与语音；在工作目录内读写和执行命令 | 危险命令（删除或覆盖工作目录外的文件、`sudo`、改系统设置、停服务、递归删除等）、写工作目录外的文件、对外发消息、明显花钱、修改自己的权限 |
| 稳妥 | 读文件、上网、记忆、提醒、图片与语音；在工作目录内写文件 | 任何命令（bash、PowerShell）、交给其他助手或子 Agent、写工作目录外的文件（弹出确认）；对外发消息、明显花钱、修改自己的权限 |
| 每次都问 | 阅读、查询和回答 | 其余每一步（弹出确认），包括在工作目录内写文件、记下关于你的事、把文件交给你和取出上传附件的原件 |

“稳妥”和“每次都问”在工具层执行：Bot 调用相应工具时，输入框上方出现确认卡，写明它想做什么（例如要运行的命令或要写的文件路径），点“允许”才执行，“不要”或 30 分钟内没有回答则这一步不执行，Bot 会改用其他办法或询问你。多步同时等待时逐个确认；某一步已被取消（例如它所在的脚本结束）时，确认卡随之消失。同一会话在 Pi Agent 页面打开时以通用确认对话框出现。定时任务运行中没有人能确认，这些步骤直接不执行，由 Bot 在回复中说明。工作目录外的判断与 Pi 写文件时的路径解析一致（含 `~`、`file://`、符号链接）；指向别处、无法解析的链接和有多个硬链接的文件都按工作目录外处理。读不到 Bot 设置时按“每次都问”处理。

“放手”中的“先问你的事”以及其余两种方式中标为未弹出确认的事项，仍是写进 Bot 指令中的工作习惯。做事方式都不是安全隔离：允许后的命令以 Pivane 服务的权限运行。无论哪种方式，Bot 都被要求不读取、不透露、不发送密码、密钥、令牌、私钥和 Pivane 自身的私密配置。

## 定时任务

在[定时任务](SCHEDULED_TASKS.md)中选择以 Bot 身份为目标时，任务发送到该 Bot 的主聊天，并始终进入主聊天当前的会话（换代后自动跟随）。已经开始的运行留在开始时的会话中完成，并一直使用任务开始时选定、用于预算核算的模型；运行结束后恢复 Bot 自己的模型。定时任务页面中 Bot 的“主线程”就是它的主聊天，不能改选或新建，页面只提供“打开主聊天”。

Bot 设置刚改过、主聊天空闲时，任务运行前会像手动“重新打开实例”一样重新打开主聊天以加载新设置，已打开的页面自动重连。主聊天正在运行、还有运行队列取回内容或扩展草稿、有侧聊或待发送的延迟消息、或配置正在保存时不会自动重开，按“线程忙碌”等待，在错过策略允许的时间内再试，超时记为跳过。

## 当前限制

- 每个 Bot 只有一个主聊天；话题窗口尚未提供。
- 空闲摘要和随后的换代在 Bot 聊天的运行实例仍打开时进行；没有页面打开时运行实例在最后一次使用 15 分钟后关闭，提示缓存时间更长的模型可能等不到空闲摘要，届时由窗口快满时的自动压缩接替，换代顺延到下一次空闲整理。
- 整理摘要会额外调用一次这个 Bot 的模型。最近一次摘要之后、Bot 自己没有记下的变化，要到下一次摘要时才同步到“我记着的事”。
- 换代时最近部分只带文字，工具输出不带入新会话；需要时 Bot 可以翻找之前的聊天。
- 微信等消息渠道不能绑定 Bot 的会话。按 Bot 绑定（换代后自动跟随）将在后续版本提供。
- Bot 不会主动发起对话，因此设置中没有安静时段。
- “放手”中的危险操作尚未在工具层识别；确认只针对单次操作，没有“以后都允许”的长期规则。
- 最多 50 个 Bot（与助手档案共用 50 个上限）。
