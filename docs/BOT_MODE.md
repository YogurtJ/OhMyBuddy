# Bot 模式

> 尚未发布：本文描述当前源码行为，正式版本不含此功能。限制见[当前限制](#当前限制)。

Bot 是有名字、样子和性格的私人助理。每个 Bot 有一个“主聊天”：像同一个人一直和你聊，不显示项目、线程、模型名或上下文压缩。Pi Agent 页面保持原样，继续面向需要完整工作台控制的使用方式；原“助手对话”页面已停用，由 Bot、话题和 Pi Agent 的“以身份新建…”承接，旧数据都保留（见[助手会话分类](AGENT_PROFILES.md#助手会话分类助手对话页已停用)）。

每个 Bot 本质上是一个[助手档案](AGENT_PROFILES.md)，有自己的“关于你”、长期记忆、技能、模型和工作目录。不同 Bot 之间互不共享这些内容。

## 开始

服务端支持时，导航栏出现“Bot”。还没有 Bot 时显示欢迎页，点“开始”创建第一个 Bot 并进入它的主聊天。新 Bot 默认使用内置“小石”头像，无需先选表情；已有 Bot 保留原头像。

Bot 需要聊天模型才能说话。没有任何可用聊天模型时，欢迎页和问候里出现“接入模型”，打开“供应商与模型”设置；接入并刷新模型目录后，Bot 页面重新检查，出现“开始”。只要有可用模型，就不需要额外选择：Bot 跟随工作台的默认模型，也可以在它的设置里单独指定。

## 互相认识

第一次打开主聊天时，Bot 在本地打招呼，这一步不调用模型。你可以开始两三分钟的访谈，也可以跳过，直接聊天。

访谈按怎么称呼你、主要帮你做什么、Bot 的名字、性格、做事方式依次进行，每次只确认当前这一项。头像已经就绪，不再单独询问或要求选择表情；想换时可以在设置中修改，也可以之后在聊天里主动提出。之后再聊一两个还需要了解的关于你的轻问题，最后给出几件马上能做的事。还没想好主要让它做什么或它该怎么说话时直接说就行，它会先按通用方式聊，以后从你的要求里看出偏好再提出修改。

每张设置卡都可以稍后再决定：不保存卡片提出的值，其中尚未处理的访谈步骤记为跳过，Bot 接着聊下一项，以后随时可以在设置中补充。已经完成或跳过的步骤保持原状。确认卡片时也可以修改或不保存其中某项；未选中或清空的项若尚未处理，也记为跳过。保留与当前相同的名字、头像、职责或性格，也算回答了该项。做事方式在自己的卡片中确认一次；夹带在其他卡片里的未变方式不会被确认或跳过。保存名字不会同时完成头像步骤，默认头像也不算用户主动选过。

做事方式在访谈中单独选择一次：[放手、稳妥、每次都问](#做事方式)。设置卡可以保持当前方式，或改得更谨慎；之后只有实际提出改变做事方式时才再次出现选择。要给 Bot 更多自由，需要在设置中修改。访谈还没结束时，在设置中改过的名字、头像、主要职责、性格和做事方式也计入各自的访谈进度。

设置卡保留标题和底部操作，内容较长时在卡片中间滚动。“主要帮你做”可以折行查看和编辑，保存时将换行整理为一句；性格保留段落。手机键盘挤占空间时，卡片和输入区随可见范围调整；空间很小时卡片可能暂时盖住头像牌，保存和以后再说仍可操作。保存失败后保留修改、阅读位置和正在编辑的位置。

名字和头像一旦定过，重新互相认识后仍保留这些选择。头像提供内置的小石、豆豆或方方三种形象，也可以上传自己的图片（PNG、JPEG、WebP、GIF，最多 6 MiB；保存时转换为 PNG），不再使用 emoji 表情；默认回退为内置“小石”。这些选择只改变样子，不关联职责、性格或模型；已有 Bot 保持原头像。点击预设先预览，保存后才生效；取消和保存冲突都沿用设置草稿规则。性格卡提供四种简短风格，也可以自由输入。访谈进度保存在 Bot 设置中，刷新、换设备或隔几天再回来都能接着聊。设置卡的确认由服务端核对：这张卡须仍在该 Bot 窗口当前一代的会话中等待回答，只接受卡上提出过的字段，并按档案修订保存；仅在其他客户端回答确认，不会写入设置。

记下的内容按用途保存：称呼、背景、目标、习惯和跨聊天的偏好放在“关于你”，本次聊天定下的事、答应的事和期限、等回答的问题、要记牢的名字和数字放在[我记着的事](#我记着的事)。同一件事也可以同时需要这两种记录。Bot 只有在保存工具成功后才会说已记下，并说明保存到了哪里。

### 第二个及以后的 Bot

新 Bot 先列出其他 Bot 已记下的“关于你”条目，默认全部勾选。取消不想让它知道的条目后选“记住这 N 条”，或选“不用，重新认识”。有多个 Bot 时可以切换来源。只复制勾选且来源中仍存在的条目，已有条目不会重复；访谈随后不再问这些内容已经回答的问题。

复制是一次性的。之后每个 Bot 的“关于你”各自保存，在一个 Bot 中更新不会同步到其他 Bot。

### 在真实项目里用 Bot

Bot 的聊天和话题都在它自己的工作目录里。要让它在某个真实项目目录里工作，在 Pi Agent 的项目菜单中选“以身份新建…”并选这个 Bot：新建的是该项目里的普通 Pi 线程，带着它的性格、记忆和技能，但工具和权限与 Pi Agent 相同，不受 Bot 的做事方式限制，也不出现在 Bot 的聊天和话题里。

### 把已有身份变成 Bot

在“身份”页选中一个已启用的助手身份，在“更多操作”中选“变成 Bot”。确认后它保留名字、头像、性格、记忆和技能，新建自己的工作目录和主聊天，出现在 Bot 页面。第一次打开时它以原来的名字打招呼，只问还没定下的事（主要帮你做什么、怎么做事；没写过性格的也会问性格），不会当作新来的重新起名，也不再从其他 Bot 复制“关于你”。

以前用这个身份进行的对话不移动、不删除，仍在 Pi Agent 的线程列表里（带身份标签），打开后照常使用它的性格和记忆，但不是 Bot 的聊天或话题。以这个身份为目标的定时任务以后发到 Bot 的主聊天，确认时会说明有几个。变成 Bot 后不能再变回普通身份，可以像其他 Bot 一样移到回收站。停用的身份要先启用。

### 认识之后的第一件事

新建或重新开始的访谈完成后，主聊天空闲时出现本地收尾卡：说明聊天、记忆和文件的保存位置，回复时使用所选模型，以及做事方式的作用范围。可以继续跟随默认模型，也可以选择一个可用模型和思考程度；保存失败或修订冲突时保留选择，成功后才显示已保存。没有额外的模型调用。

接着可选学习、安排计划、写东西、聊聊，也可自己说或以后再说。手机上保存位置与权限说明默认折叠，建议和离开选项放在可直接操作的位置。自己发了一条消息后，本页会先收起尚未选择的收尾卡；没有替你保存进度，刷新后仍可回来选择。只有你点击建议才会发送消息；输入框已有文字或附件时不会被覆盖，发送失败时文字留在输入框。这里完成的是引导中的选择，不代表 Bot 已经执行完那件事。已经完成旧版访谈的 Bot 不会自动重新进入这些步骤。

## 主聊天

Bot 的大头像悬浮在聊天顶部，下面是圆角名字牌，点头像或名字牌打开设置；空闲时用小圆点提示状态，工作、等待确认和断线等状态保留文字。头像两侧的聊天内容可以滚动到顶部，并逐渐淡出、模糊，顶部不再单独占据一整行；刚开始的消息与“更早的聊天”控件留有初始间距，这段间距会随聊天滚走。每条回复不再重复小头像。你的消息在右侧主题色浅底气泡里，Bot 回复在左侧柔和底色气泡里，表格和代码可以展开到阅读宽度；相隔十分钟以上的用户消息显示居中时间。输入框提示“给 {名字} 发消息”。工作台的项目、模型、上下文和运行控制在 Bot 页面中隐藏；需要这些控制时使用 Pi Agent 页面。Bot 聊天没有侧聊和“从此回复后分叉”：选中文字后的菜单不显示“在侧聊中提问”，回复上不显示分叉按钮，`/btw`、`/fork` 和 `/clone` 在 Bot 页面会提示不可用。

回复前做过的事收在一行“用时 · N 个步骤”里，点开可回看；这一轮往[我记着的事](#我记着的事)里记了东西时，这一行还会写“记下 N 件事”，对应步骤显示为“记到‘我记着的事’ · 内容”，翻找更早的聊天显示为“翻找之前的聊天 · 关键词”。进行中显示“正在思考”“正在处理”，需要你确认时显示“等你确认”。Bot 的记忆回执会说明保存到“关于你”还是长期记忆（旧回执缺少位置时仍显示“记下了”），可撤销、标为不对或编辑。工作台的记忆回执栏和“本轮文件”编辑记录不在 Bot 页面显示。Bot 交给你的文件显示为文件卡，点文件名在右侧（手机为全屏面板）预览，右侧下载按钮下载原文件。

Bot 的回复和普通 Pi Agent 一样可以读写文件、执行命令、上网和使用已配置的工具。它创建的文件默认放在自己的工作目录：`<位置>/PivaneBots/bot-<ID 前 8 位>/`，目录中的 README 说明归属；改名不移动目录。位置是家目录（在允许的项目根内时），否则是第一个项目根；不会放在 Pivane 服务的运行目录或安装目录里。

### 形象状态

三款内置形象共用八种姿态：待机、思考、工作中、等你、完成、出错、打盹、问候。顶部使用已有会话和工作状态：待确认事项优先保持“等你”，运行中的回复、工具或子任务显示工作姿态；仅有排队任务时保持中性姿态，文字说明排队。断线或重连暂停动态，连接情况继续用文字表达。列表、身份页和历史里的形象保持静态，系统的“减少动态”偏好会关闭动作但保留姿态与提示标记。

只有网页实际观察到的一轮正常回复结束、且没有待确认事项或其他工作时，才短暂显示完成姿态。停止、取消、断线、单次可恢复工具错误不会触发庆祝；明确终止的助手回复错误才使用出错姿态。新 Bot 的本地问候可短暂摆动一次；新工作、导航、待确认事项和页面隐藏会打断旧效果，结束后重新计算当前状态。首版不单独推断推理阶段或闲置时长，思考／打盹保留姿态但运行中回退到工作中／待机，不新增模型调用或状态轮询。未知的已保存预设安全回退显示，保留原引用以便资源恢复。

### 长期聊天的维护

主聊天可以一直用下去，工作台在后台按下面的顺序维护它，不需要操作，也不在页面上提示：

1. **省略旧的工具输出**：上下文用到窗口的 35% 以上、且一次能省下至少 1 万 token 和当前上下文的 20% 时，在回复结束后把最近 3 次发言之前、4000 字以上的工具输出换成一行说明（Bot 需要时可以重新查看）。“我记着的事”的记录和设置卡不会被省略。
2. **空闲时整理摘要**：回复结束后隔了一段时间（至少 10 分钟，模型提示缓存更久时等到缓存过期）仍没有新消息，上下文用到 55% 以上、且 Pi 原样保留的最近部分之前还有足够多（至少 2 万 token 和窗口的 20%）可以整理时，在后台整理一次摘要，下一条消息不用等它。窗口快满时 Pi 自己的自动压缩仍然生效，摘要方式相同。
3. **结构化摘要**：摘要用这个 Bot 的模型和思考程度，写成“在聊什么 / 经过 / 现在进行到哪”，并同步[我记着的事](#我记着的事)。你和 Bot 说的话完整交给摘要（很长的一条分段读），工具输出只取开头。回答缺少任何一部分、无法解析或请求失败时改用 Pi 原生的摘要，下一次回复前 Bot 会重新看到完整的“我记着的事”。
4. **换代**：当前会话文件达到 8 MiB、8000 条记录或 60 天时，接续到新的原生会话文件。换代总是紧接在一次摘要之后（通常在空闲整理时一并进行），这次摘要还会核对 Pi 原样保留的最近部分，使“我记着的事”在换代前同步；如果这次改用了 Pi 原生摘要，或摘要之后又有新的回复，就等下一次摘要。内容太少、没有可整理部分的会话暂不换代。新会话开头带有不显示的交接内容：“我记着的事”、最近的摘要、摘要之后的原话（最多 64000 字，不含工具输出）、模型和思考程度。通过维护接口手动换代时，这些原话可能还没整理过，新会话的第一次摘要会把它们当作原话读入并核对。

Bot 回答涉及更早内容时，可以在这个聊天的所有代里翻找原话（“翻找之前的聊天”），并查看某条消息前后的原文；它只读这些会话文件，结果会说明搜到了哪些部分。

### 更早的聊天

换代之前的内容显示在当前聊天上方，标为“更早的聊天 · 日期范围”，点开后逐段只读回看，“再往前看”继续展开更早一段；没有任何对话的一代自动跳过。这些内容从服务器读取原生会话文件，不启动旧会话的运行实例。

页面断线重连或换代时，Bot 页面总是重新确认主聊天当前所在的会话再连接，不会回到已经换下的旧会话。

当前会话发生过上下文压缩时，Bot 页面不显示压缩提示，压缩前的内容同样标为“更早的聊天”。

换代保留每一代完整的原生会话文件。换代过程中断时，下次打开主聊天前工作台先按原生证据恢复：只有新会话完整写入、并能证明接在旧会话最后一条记录之后时才采用，否则继续使用原会话，不会重放已经发生的对话。

### 在其他页面中

Bot 的原生会话仍会出现在 Pi Agent 页面的 `PivaneBots/bot-…` 项目下，可以按普通线程查看。它们不能移动到其他项目，也暂时不能绑定微信（见[当前限制](#当前限制)）。“助手对话”页面不列出 Bot 身份；打开指向 Bot 身份的助手对话链接时转到该 Bot 的主聊天。有 Bot 功能时，手机底栏不再显示“助手对话”，从“更多功能”进入；电脑侧栏中它排在“多媒体实验室”之后。

### 各个 Bot 在做什么

左侧 Bot 栏在其他 Bot 的头像上标出动静：琥珀色圆点表示有事等你确认，数字表示它有几个聊天出现了你还没看的新回复。聊天列表中，当前 Bot 的其他聊天也会标出“等你确认”（电脑上为琥珀色圆点，悬停可看文字）、新回复（主题色圆点）或正在忙（绿色圆点）；你正在看的聊天不另加标记，状态显示在顶部名字牌。这些标记来自页面原有的工作状态刷新，不额外启动运行实例或调用模型。

手机上有两个以上 Bot 时，菜单抽屉顶部有“所有 Bot”，其他 Bot 有新回复或等你确认时显示“另有 N 个有动静”。点开后是 Bot 首页：按设置中的顺序列出每个 Bot（顺序不会因新消息变化），显示等你确认、正在忙（以及在哪个聊天）或它主要帮你做的事，有新回复的聊天数，以及一个最值得看的话题入口；“话题 N”打开这个 Bot 的聊天和话题列表。可以按名字或话题名搜索，并筛选“等你确认”“有新回复”。工作状态暂时读不到时显示“暂时看不到它在做什么”，不会当作空闲。首页不显示消息预览或时间。点任一 Bot 进入它的主聊天，点返回或按 Esc 回到刚才的聊天；首页打开期间新回复不会被自动标为已读。上次打开的 Bot 和 Bot 地址的行为不变。

## 话题

同一个 Bot 可以有主聊天和多个话题。电脑在左侧聊天列表、手机在菜单抽屉中点“新话题”，直接打开一个全新的话题窗口并聚焦到输入框，随时开始提问；首轮问答完成后自动生成话题名与“专注什么”，后台整理摘要时也会为空白的关注点自动补充，之后随时可点话题旁的编辑按钮修改名字和关注点（已有图标的话题仍可编辑或清除图标）。每个话题从一段全新的对话开始，不复制主聊天内容；共享这个 Bot 的性格、模型和长期记忆，“我记着的事”和聊天历史各自独立。最多 100 个话题，包含已经归档的。

编辑话题时可以填“话题指令”（可不填）：在这个话题里它要一直遵守的做法，比如回答格式、资料来源。可以写多行，最多 8 KB（约 2700 个汉字）。修改从下一条消息开始生效，不用重新打开聊天；指令仍受做事方式和安全规则约束。主聊天没有话题指令；Bot 提议的话题也不带指令，只能由你自己填写。

Bot 也可以建议另开话题，确认卡会列出名字和关注点；任何做事方式都需要你确认，成功后才出现“打开话题”回执。创建不会自动打断当前聊天或切换页面。

不用的话题可以归档，历史保留；从“已归档的话题”恢复后继续使用原来的聊天。归档中的话题不接受新消息或定时运行。正在回复、等待确认、还有排队或后台工作、预约消息、侧聊、换代或关联定时任务时，先处理这些工作再归档，不会自动清掉它们。主聊天不能改名或归档。在另一台设备归档当前话题后，本页会提示并回到主聊天；当前 Bot 被移到回收站时，会刷新列表并转到其他可用 Bot 或欢迎页。修改发生冲突时保留草稿，核对刷新后的内容再保存，不自动重试。

主聊天可以看到其他活跃话题的未了事项标题索引，取自各自记事本中的待回答问题和未完成承诺。索引有数量和读取预算，忙碌、暂时不可读或超出预算表示未知，不等于没有事项；不会为此启动话题运行实例或额外调用模型。

## 我记着的事

“我记着的事”是这个聊天的记事本，记下你定下的事、答应的事（谁答应、截止哪天）、还在等答案的问题、这段聊天的偏好和要求，以及要记牢的名字、编号、数字和日期。它只属于当前聊天；跨聊天的“关于你”见设置里的“记忆和关于你”。

- Bot 在聊天中随时记下和更新，记下的那一刻就写入会话文件（Bot 从脚本里一次记几件事也一样），回执说“记下了”的事都能在列表里看到；Bot 自己没看到记录结果的（例如在脚本里记的），下一次回复前会再告诉它。整理摘要时还会对照原话补记和同步，例如你说过“不用了”的事会标为不需要。补记必须引用原话：“已经定下的”和“偏好和要求”只认你说过的话，Bot 的建议在你接受之前不算定了。
- 电脑在 Bot 列表底部（“{名字} 的设置”上方）打开，手机点顶部右侧的图钉，或在左上角菜单中打开。
- 按“答应的事、等回答的问题、已经定下的、偏好和要求、要记牢的信息”分组。答应的事和等回答的问题左侧有圆圈，点一下标为完成（已有答案）。每条可以修改内容和截止时间（日期，可再填几点几分；只说了日期的保持为日期）、标为“不需要了”或删除；删除前会再确认一次，删掉后 Bot 不再记得，之后整理摘要也不会根据删除前的原话把它记回来（你重新提起时可以再记；只记最近删除的 1000 条）。已完成、不需要了和被新内容取代的事收在底部，可以重新打开。
- 列表底部说明“关于你”的保存位置，并可直接打开它；列表为空不代表 Bot 没保存个人事实。
- 点“出处”显示这条来自哪句话（你说的、Bot 说的或查到的内容），换代后仍然保留。
- 截止时间显示为月日；有具体时刻的显示到几点几分（按这台设备的时区），不是今年的另显示年份。
- 修改在聊天空闲时保存。没保存成功时（Bot 正在回复、网络断开，或其他设备和 Bot 刚刚改过、列表已自动刷新），编辑框里你写的内容保留，可以稍后再点保存；刷新后你没动过的内容和截止时间跟着更新，保存时只提交你改过的部分。这台设备时区里不存在的时刻（夏令时开始时跳过的那一小时）不能保存，会提示换一个时间。你的修改会在下一次回复前告诉 Bot。

## 设置

点击聊天顶部的大头像，或 Bot 列表底部的“{名字} 的设置”（手机也可用左上角菜单）。设置窗口包括：

| 项目 | 说明 |
|---|---|
| 名字和样子 | 名字（最多 40 字）；小石／豆豆／方方三种内置形象或上传图片（使用自定义图片时可移除并恢复内置形象）。选择先预览，保存后生效 |
| 主要帮你做什么 | 一句话说明，Bot 会以此为主要职责 |
| 性格 | Bot 的说话方式与个性（SOUL），下一条回复起生效 |
| 用哪个模型 | “跟随默认”或指定模型及思考程度，只影响这个 Bot；所选模型暂时不可用时保留设置并继续使用当前模型 |
| 做事方式 | 放手（默认）、稳妥、每次都问，以及查看、撤销“一直允许的事”，见下文 |
| 更多 | “记忆和关于你”打开该 Bot 身份页的“关于你”；“重新互相认识”回到主聊天重新访谈；“移到回收站”停用并可恢复 Bot |

图片在保存时先上传；若上传成功而其余设置保存失败，图片已成为头像，取消离开时会提醒，可在设置里再改。预设和 emoji 不会在取消时写入。只保存改动过的字段。设置在别处刚被修改时，窗口重新读取最新设置并保留你的修改，提示检查后再保存一次。有没保存的修改时（包括暂时无效的修改，例如名字被清空），关闭、按 Esc、点“记忆和关于你”或“重新互相认识”都会先提醒一次，再做一次同样的操作才放弃修改。

### 移到回收站

在 Bot 设置中点“移到回收站”，确认后停用这个 Bot，从列表隐藏；聊天、工作目录、记忆和文件都保留，可以到“身份”页的回收站恢复。设置有未保存修改时会先提醒。Bot 仍在工作、排队或有后台任务、未处理的预约消息、关联的定时任务及已受理但未完成的定时运行时，操作会被拒绝，不会自动取消这些内容。成功前会核对修订和原生窗口身份，并停止该 Bot 的空闲运行实例；失败时保留设置窗口，不假称已移走。

### 做事方式

| 方式 | Bot 直接做的事 | 先问你的事 |
|---|---|---|
| 放手（默认） | 相当于完全权限：阅读、上网、记忆、提醒、图片与语音；写任意普通文件（含 Shell 配置等）；运行命令、脚本、安装依赖、`ssh`/`scp`、`docker` 等 | 短名单：`sudo` 等提权、递归或磁盘级删除（`rm -r`、`find -delete`、`mkfs`、`dd of=`）、关机、结束进程和服务控制、`git push`／`reset --hard`／`clean -f`／`branch -D`、发布包或版本、发邮件、定时或开机自启任务，以及读写 Pivane 自身的 `.pivane-runtime` 目录；写目录、自启动位置和工具标记为破坏性的操作；对外发消息、明显花钱和修改自己的权限仍须先确认 |
| 稳妥 | 读文件、上网、记忆、查看定时任务、图片与语音；在工作目录内写文件 | 创建或取消定时任务、任何命令（bash、PowerShell）、交给其他助手或子 Agent、写工作目录外的文件（弹出确认）；对外发消息、明显花钱、修改自己的权限 |
| 每次都问 | 阅读、查询和回答 | 其余每一步（弹出确认），包括在工作目录内写文件、记下关于你的事、把文件交给你和取出上传附件的原件 |

三种方式都在工具层检查：需要确认时，输入框上方出现卡片，写明要运行的命令、文件路径或其他操作；点“允许”只允许这一次，“不要”、取消或 30 分钟内没有回答则不执行。Bot 不会重放或绕过未获允许的步骤。多步等待时逐个确认；某一步已被取消时，卡片随之消失。同一会话在 Pi Agent 页面打开时使用通用确认对话框。定时任务运行中没有人确认，需要确认的步骤直接不执行。读取设置失败时使用“每次都问”，不沿用不确定的长期规则。

对于规则能理解的非危险命令或单个文件写入，确认卡还可选择“以后都允许”。第一次点击会展示确切操作和作用范围，再次确认才保存，并只在原请求仍有效时允许当前这一步。规则只匹配同一工具、同一工作目录与完全相同的命令，或同一工具与确切文件路径；不是通配符、整目录或任意命令授权。危险、无法判断或敏感操作不提供这个选项，长期规则也不能绕过它们。在设置中可查看和撤销已识别规则，撤销与其他修改一起保存；当前版本不识别的旧规则保留但不作为授权使用。修订冲突时不自动新增规则或回答确认。

Bot 的目录内容搜索会逐个核验文件，再在已核验的内容上匹配；敏感文件不会因为搜索了父目录而带入结果。搜索有文件数量、大小和时间上限，文件改变、编码不支持或预算用尽时会说明结果不完整，不能据此断言其他文件没有相关内容。PowerShell 文件选择器中的通配符不能获得一次或长期放行；明确的字面路径仍按路径规则检查。

路径检查与 Pi 工具的路径解析保持一致，并核对可识别的真实路径、符号链接和硬链接；无法可靠判断的文件身份拒绝访问。任何方式都拒绝可识别的凭据文件、私钥和 Pivane 私密状态路径，不能用一次确认或长期规则解除。它仍是工具层的规则检查，**不是操作系统沙箱**：允许的命令以 Pivane 服务权限运行，不会隔离其程序内容、环境或后续行为；“稳妥”和“每次都问”中复杂程序和无法理解的命令需要单次确认；“放手”只识别上表短名单，藏在复杂脚本里的危险操作不一定能认出来，风险与普通 Agent 的完全权限相同。查看整个环境变量（`env`、`printenv`、不带参数的 `export`／`set`）在任何方式下都拒绝，设置变量后运行命令不受影响。对外发送、明显花钱等不能从工具参数可靠识别的意图，还依赖 Bot 的指令和对应功能自身的确认流程。

## 定时任务

可以直接在聊天里请 Bot 创建单次提醒或重复任务、查看任务、取消任务。一次还是重复、哪一天不明确时，Bot 会先问清楚；只有工具成功后才说已设好，并报出本地时间和时区。按“做事方式”，“放手”直接执行，“稳妥”和“每次都问”在创建、取消前显示确认卡，查看任务无需确认。任务也可以在[定时任务](SCHEDULED_TASKS.md)页面查看和编辑。聊天里创建的任务发到提出请求的窗口（主聊天或话题），换代后自动跟随该窗口；用户要求的任务按指定时间执行，不受安静时段影响。定时任务运行中不能再创建任务。

成功的聊天工具结果显示定时任务卡，列出标题、时间、时区和要做的事；“查看 / 修改”直接打开该任务，取消时核对调度器的当前修订，冲突时不自动重试。卡片是创建／取消时的回执，任务当前状态以定时任务页面为准。

## 主动找你

Bot 可以自己发起两类消息：你和它说好的事（记在“我记着的事”里、带截止时间的承诺）到期时，它会来提醒你或问问进展；聊天中觉得过几天回来看看确实有帮助、而你没有要求提醒时，它可以给自己约一次“回来看看”（只此一次、最多 60 天后，每个 Bot 同时最多 10 个）。这些消息只发文字，不使用工具、不会自己动手做事，发到原来的主聊天或话题里，聊天中显示为“主动跟进”卡片，只露出简短标题。只写日期的承诺在当天上午 9 点跟进；改了截止时间会改到新时间，标为完成或取消后不再跟进，同一条已发过的不会重复。到期时如果服务停了超过两小时、话题已归档或 Bot 已移到回收站，这次跟进不再补发；聊天正忙时稍后再发。

在 Bot 设置的“主动找你”中可以：

- 关掉“让它主动找我”：不再新增或发送这类消息（已排队还没开始的也不发），也不再推送；Bot 也不再给自己约回来看看。你要它设的提醒和定时任务不受影响。
- 设安静时段（默认 23:00–08:00，按保存设置时浏览器的时区）：这段时间里它主动发的消息照样出现在聊天里，但不推送、页面也不提醒；安静时段结束后合成一条推送，告诉你它留了几条消息，还没读的聊天在打开的页面上再提醒一次。
- 设每天的推送上限（默认 20 条，可选“不限”）：只计算它主动发的消息的推送，合成的那一条算一条。超出后消息仍留在聊天里，只是不再推送。和它聊天、引导和设置、你要的提醒都不计入，所以刚开始频繁设置 Bot 时不会用完。
- 查看“准备跟进的事”，逐条取消。已经开始发送的不能撤回。

Bot 自己约的回来看看，它也可以自己取消；要取消你的承诺的到期提醒，按“做事方式”和取消定时任务一样先确认（“放手”除外）。

这类消息不占用定时任务的每日执行和 token 预算，另有每个 Bot 每天 50 次的安全上限；它们不出现在定时任务页面，也不推送到微信等消息渠道。

在定时任务页面选择以 Bot 身份为目标时，任务发送到该 Bot 的主聊天，并始终进入主聊天当前的会话（换代后自动跟随）。已经开始的运行留在开始时的会话中完成，并一直使用任务开始时选定、用于预算核算的模型；运行结束后恢复 Bot 自己的模型。定时任务页面中 Bot 的“主线程”就是它的主聊天，不能改选或新建，页面只提供“打开主聊天”。

Bot 设置刚改过、主聊天空闲时，任务运行前会像手动“重新打开实例”一样重新打开主聊天以加载新设置，已打开的页面自动重连。主聊天正在运行、还有运行队列取回内容或扩展草稿、有侧聊或待发送的延迟消息、或配置正在保存时不会自动重开，按“线程忙碌”等待，在错过策略允许的时间内再试，超时记为跳过。

## 当前限制

- 每个 Bot 有一个固定主聊天及最多 100 个话题；归档话题计入数量上限。
- 空闲摘要和随后的换代在 Bot 聊天的运行实例仍打开时进行；没有页面打开时运行实例在最后一次使用 15 分钟后关闭，提示缓存时间更长的模型可能等不到空闲摘要，届时由窗口快满时的自动压缩接替，换代顺延到下一次空闲整理。
- 整理摘要会额外调用一次这个 Bot 的模型。最近一次摘要之后、Bot 自己没有记下的变化，要到下一次摘要时才同步到“我记着的事”。
- 换代时最近部分只带文字，工具输出不带入新会话；需要时 Bot 可以翻找之前的聊天。
- 微信等消息渠道不能绑定 Bot 的会话。按 Bot 绑定（换代后自动跟随）将在后续版本提供。
- Bot 主动发的消息只有到期跟进和它自己约的回来看看两类，只发文字；安静时段按保存设置时浏览器的时区计算，没保存过则按服务器时区。
- 工具权限是规则识别，不是沙箱；它不会分析被允许的程序内部行为。长期规则只覆盖可以理解的精确命令或单个文件，微信审批尚未提供。
- 最多 50 个 Bot（与助手档案共用 50 个上限）。
