# OhMyBuddy 1.11.0（Pi 1.4.0）

Pivane更名为 **OhMyBuddy**。版本号延续，网页品牌、新图标、新安装包／服务／配置名称统一更新；旧安装原位读取，历史会话与浏览器偏好保持兼容。导航中的 Bot 与 Pi Agent 分别显示为“伙伴”（Buddy）和“工作台”（Workspace），接口与数据名称不变。公开仓库更名为 `YogurtJ/OhMyBuddy`，GitHub 保留旧地址跳转；1.11.0 的更新检查只跟随同源 GitHub API 跳转，1.10.x 及更早版本的更新检查不跟随跳转，需要按[安装与恢复](../INSTALL_RECOVERY.md)手动升级一次。详见[命名与升级](../development/NAMING.md)。

本页描述1.11.0已实现的功能。准确归档SHA256、三平台执行结果及证据复用关系见对应包外验收附件，公开下载以[GitHub Releases](https://github.com/YogurtJ/OhMyBuddy/releases)为准。源码完成、实例部署和正式发布是独立步骤。

## 伙伴模式

[伙伴](../BOT_MODE.md) 是有名字、形象、性格、工作目录和做事方式的私人助理。主聊天与最多100个话题各有独立原生对话和“我记着的事”，共用当前伙伴的档案记忆与技能。话题支持关注点、多行指令、归档和恢复，旧代可只读回看并按原文检索；不同伙伴不自动共享记忆。

长聊天可以整理结构化摘要、按原话同步记事本，并在可验证的摘要边界换代。微信用户输入只有在原生运行凭据匹配时才参与回忆、摘要、交接和后台学习，保留出处；系统、定时与子任务通知不当作用户，旧引文不重复学习，也不凭旧出处复活已删除笔记。Pi原生JSONL仍是对话事实来源。

网页设置、认识收尾卡和微信共用持久设置。模型与思考等级独立保存，恢复默认模型保留思考偏好；跟随默认显示实际选择，不把自动选择写成固定模型。新组合按实际模型能力校验；后续回复采用新选择，进行中回复及已准入任务保持原模型和计价边界。

伙伴设置按资料、模型、做事方式、主动联系、微信、学习与记忆、更多分区组织。手机先显示概览。跨页、跨伙伴、地址及浏览器前进／后退时保护未保存草稿，保存或头像解码中保留原表单，迟到结果不覆盖其他伙伴。最近活动区分执行与投递，只从有界近期来源筛选当前伙伴；未知费用不当作零，推送额度不等于费用上限。

手机认识收尾卡在回复开始／结束和刷新时保留最后的展开选择，忽略已移除节点的迟到折叠事件。macOS 系统与自启动路径的 `/private` 别名沿用相同权限分类，不能凭别名保存长期允许。

## 微信操作

[微信渠道](../MESSAGE_CHANNELS.md) 支持 `/help`、`/status`、`/stop`、`/confirm`、持久化 `/model` 与 `/thinking`，以及 `/bot`（`/伙伴`、`/buddy`、`/切换`）、`/topic`（`/话题`）。`/new` 新建并进入话题，`/name` 修改当前话题名称；`/help advanced` 提供详细状态、结构化 `/compact` 与空闲 `/reload`。恢复默认使用 `/model default`、`/thinking default`。`/resume`、`/reset` 保留限制并说明话题替代操作。

工具授权通过“同意／拒绝 A编号”回答原来那一步；媒体 `/confirm [卡片ID]` 单独确认或查询媒体卡片。两者不互相代替，失败或结果不确定不重放。执行前明确的无模型／不支持图片拒绝会解释原因并释放后续队列；超时及任意RPC错误仍保留不确定边界。

回复或通知的发送故障与后续聊天隔离。明确尚未发送的连接、限流和上传故障有限重试；不确定投递不重放。服务重启后可依据原生完成证据恢复尚未发送的结果，不重新执行任务。

## 聊天过程与状态回执

伙伴的一轮回复用一行过程、最终回复及必要的状态回执呈现。过程可以展开查看步骤和原始输出；中途失败后继续完成的步骤不会被展示成整轮失败。记忆、记事本、技能、设置和定时等状态变化仍有可查看的回执。普通工作台的详细过程视图保留。

伙伴通过普通写入工具修改规定档案文件时，可补充变更回执。它只报告可核实的变化，不输出设置值或凭据；读取失败、超预算或无法判断时跳过。同一伙伴其他聊天或后台学习在相同时间窗口的变化可能被归到当前工具，同指纹的快速原地改写可能无法识别，此回执不构成完整审计日志。

## 图片、附件与工作台

原生会话中的图片按内容哈希保存在不可变私有对象中，JSONL保存引用；请求模型时恢复相同字节，保留图片Token粗估和压缩语义。导出时重新内联，导入、分叉、编辑、媒体参考图和侧聊兼容。完整恢复必须同时保留原生会话与其引用的私有图片对象；不要仅复制JSONL。已有内联历史继续兼容，离线历史转换需要单独规划、停机备份和原生语义校验，不会因本版更新自动全量改写。

档案索引按去除图片载荷和推理签名后的文本计量，避免大图片使可搜索文本被整体跳过。附件管理提供容量、搜索、状态、原件下载与来源入口；引用核对不完整时不授权清理。带图消息收到原生回显后展示，减少临时消息与回显重复；手机长草稿下的附件菜单按实际可见空间定位并内部滚动。

子Agent面板显示角色、模型、思考、当前工具、耗时和费用，保留键盘、菜单及引导的实际送达状态。模型与思考选择提供切换反馈和完整等级菜单；导航布局调整不再误关思考菜单，实际窗口尺寸变化仍保留选择后关闭。受管线程重开时，定时扩展不再丢弃尚在注册的已选工具，包括最后一次模型请求来自定时任务的恢复情形；普通回合在启动注册完成后清理静默结束工具，子任务回复选择和明确禁用保持原生语义。任务结果可在来源运行期间先标为已读，正文回执仍待来源空闲纳入。修复备份保留预算、同树硬链接清理及定时任务对账等边界。

## 权限与升级

伙伴默认“放手”具有普通Agent的系统权限；工具规则不是操作系统沙箱。需要确认的操作和无人值守限制见[伙伴权限说明](../BOT_MODE.md)。主动联系与用户定时任务各有独立开关和额度，后台学习另用辅助模型，当前没有整个伙伴的统一费用账本。

Pi保持1.4.0，内置pi-subagents更新至0.82.1，undici固定为8.12.3。请使用本版锁文件通过正常安装流程更新依赖，不复用不匹配的旧node_modules。升级前保存草稿，等待实际工作结束，按[安装与恢复](../INSTALL_RECOVERY.md)停机备份并保留固定数据路径。不会因重构删除会话、媒体、历史或prompts；未知结果不重放，服务接受新消息后不能用旧数据盲目回退。
