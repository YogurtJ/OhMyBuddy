# Pivane 1.11.0 候选（Pi 1.4.0）

本页描述正在准备的1.11.0候选，尚未公开发布。最终下载、准确归档SHA256、三平台执行结果及证据复用关系以发布时的包外验收附件为准。源码合并、实例部署和正式发布是独立步骤。

## Bot 模式

[Bot](../BOT_MODE.md) 是有名字、形象、性格、工作目录和做事方式的私人助理。主聊天与最多100个话题各有独立原生对话和“我记着的事”，共用当前Bot的档案记忆与技能。话题支持关注点、多行指令、归档和恢复，旧代可只读回看并按原文检索；不同Bot不自动共享记忆。

长聊天可以整理结构化摘要、按原话同步记事本，并在可验证的摘要边界换代。微信用户输入只有在原生运行凭据匹配时才参与回忆、摘要、交接和后台学习，保留出处；系统、定时与子任务通知不当作用户，旧引文不重复学习，也不凭旧出处复活已删除笔记。Pi原生JSONL仍是对话事实来源。

网页设置、认识收尾卡和微信共用持久设置。模型与思考等级独立保存，恢复默认模型保留思考偏好；跟随默认显示实际选择，不把自动选择写成固定模型。新组合按实际模型能力校验；后续回复采用新选择，进行中回复及已准入任务保持原模型和计价边界。

Bot设置按资料、模型、做事方式、主动联系、微信、学习与记忆、更多分区组织。手机先显示概览。跨页、跨Bot、地址及浏览器前进／后退时保护未保存草稿，保存或头像解码中保留原表单，迟到结果不覆盖其他Bot。最近活动区分执行与投递，只从有界近期来源筛选当前Bot；未知费用不当作零，推送额度不等于费用上限。

## 微信操作

[微信渠道](../MESSAGE_CHANNELS.md) 支持 `/help`、`/status`、`/stop`、`/confirm`、持久化 `/model` 与 `/thinking`，以及 `/bot`（`/切换`）、`/topic`（`/话题`）。`/new` 新建并进入话题，`/name` 修改当前话题名称；`/help advanced` 提供详细状态、结构化 `/compact` 与空闲 `/reload`。恢复默认使用 `/model default`、`/thinking default`。`/resume`、`/reset` 保留限制并说明话题替代操作。

工具授权通过“同意／拒绝 A编号”回答原来那一步；媒体 `/confirm [卡片ID]` 单独确认或查询媒体卡片。两者不互相代替，失败或结果不确定不重放。执行前明确的无模型／不支持图片拒绝会解释原因并释放后续队列；超时及任意RPC错误仍保留不确定边界。

回复或通知的发送故障与后续聊天隔离。明确尚未发送的连接、限流和上传故障有限重试；不确定投递不重放。服务重启后可依据原生完成证据恢复尚未发送的结果，不重新执行任务。

## 聊天过程与状态回执

Bot的一轮回复用一行过程、最终回复及必要的状态回执呈现。过程可以展开查看步骤和原始输出；中途失败后继续完成的步骤不会被展示成整轮失败。记忆、记事本、技能、设置和定时等状态变化仍有可查看的回执。普通Pi Agent的详细过程视图保留。

Bot通过普通写入工具修改规定档案文件时，可补充变更回执。它只报告可核实的变化，不输出设置值或凭据；读取失败、超预算或无法判断时跳过。同一Bot其他聊天或后台学习在相同时间窗口的变化可能被归到当前工具，同指纹的快速原地改写可能无法识别，此回执不构成完整审计日志。

## 图片、附件与工作台

原生会话中的图片按内容哈希保存在不可变私有对象中，JSONL保存引用；请求模型时恢复相同字节，保留图片Token粗估和压缩语义。导出时重新内联，导入、分叉、编辑、媒体参考图和侧聊兼容。完整恢复必须同时保留原生会话与其引用的私有图片对象；不要仅复制JSONL。已有内联历史继续兼容，离线历史转换需要单独规划、停机备份和原生语义校验，不会因本版更新自动全量改写。

档案索引按去除图片载荷和推理签名后的文本计量，避免大图片使可搜索文本被整体跳过。附件管理提供容量、搜索、状态、原件下载与来源入口；引用核对不完整时不授权清理。带图消息收到原生回显后展示，减少临时消息与回显重复；手机长草稿下的附件菜单按实际可见空间定位并内部滚动。

子Agent面板显示角色、模型、思考、当前工具、耗时和费用，保留键盘、菜单及引导的实际送达状态。任务结果可在来源运行期间先标为已读，正文回执仍待来源空闲纳入。修复备份保留预算、同树硬链接清理及定时任务对账等边界。

## macOS 完整平台包预览

新增[macOS完整平台包](../MACOS.md)构建与安装入口，包含独立Node22、锁定依赖和本地工具，安装到Application Support并使用用户LaunchAgent。配置了签名分发源的完整包可以通过独立启动器及一次性票据更新，保留停机备份与失败恢复。源码归档继续使用原安装和更新方式。

完整平台包与源码包分别命名和验收，不以源码测试代替DMG、安装或更新验证。预览包的系统签名／公证状态、实际架构、普通用户首次打开及下载接入范围必须在对应附件中明确说明；本候选说明不代表这些项目已经全部验收。

## 权限与升级

Bot默认“放手”具有普通Agent的系统权限；工具规则不是操作系统沙箱。需要确认的操作和无人值守限制见[Bot权限说明](../BOT_MODE.md)。主动联系与用户定时任务各有独立开关和额度，后台学习另用辅助模型，当前没有整个Bot的统一费用账本。

Pi保持1.4.0，内置pi-subagents更新至0.82.1，undici固定为8.12.3。请使用候选锁文件通过正常安装流程更新依赖，不复用不匹配的旧node_modules。升级前保存草稿，等待实际工作结束，按[安装与恢复](../INSTALL_RECOVERY.md)停机备份并保留固定数据路径。不会因重构删除会话、媒体、历史或prompts；未知结果不重放，服务接受新消息后不能用旧数据盲目回退。

## 验证状态与首版范围

发布准备以正式1.10.2及其可追溯验收链为基线，根据实际代码、依赖、安装和平台变化补验。Linux ARM64、Apple M2 macOS与Windows11 x64分别在隔离环境验证；Windows普通权限与提升权限结果分开，M1旧证据不能冒充M2实机。本候选尚在执行三平台验收，不能将源码语法检查、旧版本结果或局部模拟当作准确包通过。

语音自动转写、更多渠道、完整微信表单、Bot整体导出／迁移、自动跨Bot共享记忆和复杂主动工具仍延期。真实供应商／微信业务、Safari、其他架构以及真实手机键盘、麦克风和后台行为，只有实际验证后才能列入声明范围。

## English

Pivane 1.11.0 is being prepared and has not been publicly released. It introduces Bot conversations, persistent model and thinking preferences, topic and memory workflows, expanded WeChat controls, compact turn progress and visible state-change receipts. Native session images use immutable private objects while exports remain self-contained. The release also updates bundled subagent support, delivery recovery and attachment usability, and adds a separately validated macOS full-package preview.

Validation will identify the exact archive, checks performed on Linux ARM64, Apple M2 macOS and Windows x64, and unaffected evidence reused from earlier releases. Keep native sessions together with their referenced image objects when backing up. Tool approvals and media confirmations remain separate. Publishing a release does not automatically update an existing instance.
