# OhMyBuddy 1.12.0（Pi 1.5.0）

当前候选为 **1.12.0-rc.1**，正在进行发行验收，尚未公开发布。新完整包目标为 macOS ARM64（Apple Silicon）、Windows x64 和 glibc Linux x64；实际可下载产物与验证结论以对应 [GitHub Release](https://github.com/YogurtJ/OhMyBuddy/releases) 为准。

## Pi 1.5 与模型接入

八个官方 Pi 包统一锁定到 1.5.0，工具参数沿用原生 pi-schema 校验与转换。TypeBox 和普通 MCP JSON Schema 都继续支持；权限检查与执行使用同一份规范化参数，历史 toolCall 参数保持原样。

图片兼容包装保留同一 ModelRuntime 的认证身份，使分支摘要和压缩继续使用已保存的 OAuth 认证。MCP 配置页增加自动、DCR、CIMD 客户端注册方式，保存沿用原生验证、修订和凭据保护。官方 OpenAI Terra 增加 Fast，Sol 增加 Ultrafast；能力按实际供应商、模型、API 和官方地址判断，价格说明见[供应商与模型](../PROVIDER_SETTINGS.md)。

费用统计区分供应商实报和目录价／档位估算。供应商实报的零费用仍为有效账单，不额外补算或重复乘速度倍率。现有费用账本从 v1 事务追加到 v2，保留旧事实与累计总额；升级前须保存完整账本备份，退回旧版时配套恢复。原生 JSONL 不迁移。

从定时任务检查点恢复普通对话时，会移除只供定时任务使用的静默结束工具，并保留其他显式工具选择，防止后续扩展带回旧检查点中的定时工具。

pi-subagents 与档案记忆包保持各自已审查版本，本次没有一并升级所有第三方扩展。

## 官方 Playwright MCP 浏览器

浏览器能力复用锁定的官方 Playwright MCP，通过 Pi 原生 MCP 注册、发现和调用。扩展中心提供启用、系统 Chrome／Edge 检测及按需准备浏览器；每个持久对话使用独立浏览器资料，支持表单、截图和上传下载，重开后可保留该对话的登录资料。

停止会话后关闭原生 MCP 连接，实际清理完成前继续占用生命周期与维护状态。登录资料、下载和截图属于用户数据，遵守私密路径和备份规则。升级本身不自动下载浏览器或启用设置；外部网页执行需要用户按任务授权。详见[浏览器助手](../BROWSER.md)。

## 工作台、任务和项目

无需项目的对话进入“任务”专区，每项任务有独立持久工作目录。任务与项目分别展示，支持分区折叠，任务按每次十条继续显示；删除聊天保留独立工作文件。

打开项目支持路径层级、上一级、名称筛选与固定底部操作。本机桌面可使用系统选窗；远程或无桌面时继续浏览服务器目录。首次进入可直接新建任务或打开项目，不强制先选项目。

对话开始前，输入区可更换项目。服务端只允许移动空白会话，并核对修订、目录与原始身份；会话 ID、草稿和附件沿既有保护保留。发出首条消息后隐藏该入口。由 Buddy 发起的扩展助手和档案起草继续使用对应工作目录。

## 流式显示、扩展日志与侧聊

主聊天和侧聊复用普通 Markdown 的稳定渲染块，减少长代码前缀的重复清理和 DOM 构造。完整正文仍参与分词，晚到引用与最终修正保持原语义；原始 HTML、公式、Mermaid、未知 token 或超预算内容回退完整渲染，保留清理与执行边界。

已安装扩展包菜单增加“更新说明”，按需读取安装包的 CHANGELOG.md 或作者声明的 pi.changelogPath。预览绑定当前安装版本和配置修订，不联网读取未安装版本；包外路径、符号链接、无效编码和超预算内容被拒绝。更新成功可显示前后版本。详见[原生设置](../NATIVE_SETTINGS.md)。

Buddy 更多菜单与共享侧聊布局更紧凑，手机字号和内部滚动保持；侧聊不再重复展示主任务进度，清空重聊保留明确选择的模型与思考等级。

## 定时任务与图片生命周期

定时任务按当前安排、重复、单次、暂停及历史分组，提供可搜索线程和项目目录选择、每周设置、易读频率与可选限额。默认工作模式不限制模型调用次数，最长六小时；Token、每日次数与估算费用额度可按需设置。保留旧任务显式限制，失败记录显示原因、用量与建议；修改配置不会重放失败或不确定的任务。

会话和 Buddy 话题删除接入外置图片生命周期。回收站和归档继续保护图片；确认隔离无引用图片后至少保留三十天，再另行确认永久清理。部分删除、引用变化或结果不确定时保留相关图片。详见[定时任务](../SCHEDULED_TASKS.md)与[附件清理](../COMPOSER_TOOLS.md#附件用量与清理)。

## 安装、升级与恢复

新安装将程序、配置、运行状态、媒体、缓存与工作文件分开保存；Bot 与任务共用独立工作根。已有 Pi 身份、原生会话、配置及已保存 cwd 沿兼容规则读取，冲突时明确拒绝。升级不自动搬迁历史数据；需要迁移时按[存储布局](../STORAGE_LAYOUT.md)先停机备份并核对原生语义。

源码安装使用 Node 22.x（至少 22.19.0）与锁定依赖。完整包包含各平台独立运行环境，不复用维护者 node_modules 或身份。Linux 完整包面向 glibc，暂停新 Linux ARM64 包；历史 ARM64 附件与验收保留其原有适用范围。

升级前保存未发送内容、等待实际工作结束、正常停机并备份原生会话、私有图片对象、配置、媒体及费用账本。保留上一版与匹配恢复依赖，不并行运行共用同一身份的两个版本。详见[安装与恢复](../INSTALL_RECOVERY.md)。

## 验证范围

源码专项和本机启用结果按内容复用，正式发行仍需覆盖所声明平台的相关 Node、浏览器、原生组件、安装、旧版升级、正常停机和原路径恢复。每项结果绑定实际提交、环境与包 SHA256；未执行或未解释的失败不会标为通过。进展见[平台验证范围](../RELEASE_INSTALL_VALIDATION.md)。

真实模型或 OAuth 供应商、外部网站业务、微信投递、Safari、实体手机、系统签名与公证，以及其他架构分别记录，不由本轮合成服务或浏览器模拟代替。本候选的三平台发行结果仍在收集中。

## English

OhMyBuddy 1.12.0-rc.1 is a release candidate based on Pi 1.5.0. It adds native Playwright MCP integration, persistent standalone tasks, improved project navigation, stable-block streaming Markdown rendering, installed-package release notes, MCP OAuth client-registration controls, and provider-reported cost provenance.

New installations separate program files, configuration, state, media, cache, and user workspaces. Existing native sessions and image objects remain intact. The usage ledger receives an additive v1-to-v2 migration; keep the matching ledger backup for rollback. Scheduler editing and failure feedback improve without replaying uncertain runs.

The intended full-package targets are macOS Apple Silicon, Windows x64, and glibc Linux x64. New Linux ARM64 packages are paused. Platform qualification is in progress; this candidate has not been publicly released. Exact archives, checksums, executed checks, reused evidence, and limitations belong to the final release attachments.
