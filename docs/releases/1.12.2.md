# OhMyBuddy 1.12.2（Pi 1.5.0）

**1.12.2 / Pi 1.5.0** 于 2026-11-08 [正式发布](https://github.com/YogurtJ/OhMyBuddy/releases/tag/v1.12.2)并设为 Latest，八份附件匿名完整回下载摘要一致。冻结源码 `eb22a0215d66004b04a4e9ebb6cd68a5045b78a2`，源码包 SHA256 `55a4602eba6625ca9f53f89a66676ef0873de868ce2e1fa9f5187c7f1553ccdf`（2,031 个清单文件）。本版聚焦**伙伴身份术语统一**、**浏览器设置页改版与发现页去重**、**伙伴做事方式三档重构**、**侧聊临时附件上传与自动释放**、**微信启动提示与回复恢复改进**及英文界面补齐。Pi 1.5.0、依赖锁定图、原生组件、会话 JSONL 与 v2 费用账本结构保持不变。三平台实际执行与基线复用记录见 [Release 验收附件](https://github.com/YogurtJ/OhMyBuddy/releases/tag/v1.12.2)与[平台验证范围](../RELEASE_INSTALL_VALIDATION.md)。

## 伙伴身份、做事方式与浏览器设置

- **统一“伙伴身份”术语**：导航栏、设置面板标题、工作台会话详情栏、定时任务身份选择器及伙伴聊天更多菜单中的“助手身份／助手身份详情”统一改为“伙伴身份／伙伴身份详情”（英文 `Buddy identities` / `Buddy identity details`）；身份页内部的设定、记忆、技能与后台学习说明同步统一使用“伙伴”（`Buddy`）。详见[伙伴身份](../AGENT_PROFILES.md)。
- **伙伴做事方式三档重构**：“放手”调整为与工作台普通 Agent 一致的完全放手，不再做工具层命令与路径拦截；原“放手”策略（普通命令、任意普通文件与 `.pi/agent`／`ohmybuddy-profiles`／`ohmybuddy-bots` 等状态路径直接放行，短名单高风险操作与凭据／私钥单次确认）下移为新的“稳妥”模式；淘汰旧“稳妥”中逢命令和工作目录外写文件必问的限制，“每次都问”保持不变。详见[伙伴模式](../BOT_MODE.md)。
- **重新设计浏览器设置与扩展发现去重**：扩展 → 浏览器改为卡片式页头、连接状态摘要（浏览器程序、使用中的任务、运行方式）、开关式运行设置和独立程序操作区，使用说明分组展示，保存按钮仅在改动后可用，手机端按单列排布；扩展 → 发现不再重复展示 Pi 原生 MCP 卡片和 MCP 类型筛选，统一在独立 MCP 页签管理。详见[浏览器助手](../BROWSER.md)与[Pi 原生设置](../NATIVE_SETTINGS.md)。

## 侧聊临时附件、微信渠道与多语言细节

- **侧聊临时附件上传与自动释放**：工作台与伙伴模式的侧聊输入框新增临时附件上传（回形针选择、粘贴与拖放），支持图片、文本、Office/PDF 文档及通用原件，有工具侧聊可通过 `read_document` 和 `get_attachment` 只读读取；附件仅保存在当前侧聊内存或受管临时目录，不写入持久上传库或项目 `.ohmybuddy-attachments`，在清空侧聊、更新背景新开、闲置过期或连接关闭时自动释放。同时修复 Windows 上有工具侧聊因默认保留 `bash` 而在无 Git Bash 环境启动失败的问题（Windows 仅启用 `powershell`）。详见[侧聊](../SIDE_CHAT.md)。
- **微信启动提示与回复恢复改进**：新增绑定级“启动提示”可选项（默认开启），服务启动或重启恢复连接后发送上线提示，不写入线程上下文，缺少或过期回复上下文（返回码 `-2`）直接静默跳过并带 60 秒冷却；修复伙伴主聊天附带隐藏记事本／话题索引时回复停在“运行中”的问题，并支持对旧失败记录按已完成线程回执只读恢复发送；过期上下文（返回码 `-2`）的定时通知和线程结果改为“等待微信消息”并在下一条消息后补发（超过一天不再补发）；执行结果不确定时最多暂停该聊天 5 分钟。详见[微信与消息渠道](../MESSAGE_CHANNELS.md)。
- **英文界面补齐**：新建伙伴与一键新建话题按当前界面语言使用“新伙伴 / New buddy”和“新话题 / New topic”；补齐定时任务目录选择按钮、侧聊状态、预约草稿与跨项目线程提示、请求速度“未确认”、图片读取失败及原件附件数量上限的英文文案。

- **安装与升级兼容**：沿用 1.12.0/1.12.1 的存储布局、Pi 1.5.0 引擎与 v2 费用账本，无需迁移原生会话或账本。完整平台包覆盖 **macOS ARM64（Apple Silicon）、Windows x64、glibc Linux x64**；新 Linux ARM64 完整包继续暂停，历史附件保留原适用范围。详见[安装与恢复](../INSTALL_RECOVERY.md)。
- **按需定向验收与基线复用**：三平台完成受影响的 Node 单元/集成测试、Chromium 桌面与手机视口回归、准确新包构建与探针，以及从正式 1.12.1 完整包到 1.12.2 的单次签名更新、停机备份与原路径恢复验证；未受模块按规则复用 1.12.1 / 1.12.0 验证基线。详见[平台验证范围](../RELEASE_INSTALL_VALIDATION.md)。

## English

OhMyBuddy 1.12.2 (with Pi 1.5.0) unifies Buddy identity terminology across the UI, redesigns the Browser Assistant settings panel and removes duplicate MCP cards from extension discovery, refactors Buddy work styles so Hands-off matches Workspace Agent freedom while Careful adopts the former Hands-off policy, adds ephemeral file and document uploads to side chat with automatic resource cleanup, improves WeChat startup notices and reply recovery, and completes missing English UI strings.

Pi 1.5.0, the locked dependency graph, native addons, native session JSONL files, and the v2 usage ledger remain unchanged from 1.12.1. Full platform packages target macOS Apple Silicon, Windows x64, and glibc Linux x64 (new Linux ARM64 packages remain paused). Qualification combines targeted Node and Chromium desktop/mobile checks across all three platforms, fresh package probes, and single-execution signed upgrades and restores from 1.12.1, while reusing unchanged baseline evidence by scope.
