# OhMyBuddy 1.12.1（Pi 1.5.0）

**1.12.1 / Pi 1.5.0** 为 1.12.0 之后的小版本更新，聚焦**自定义服务商一键接入与模型自动探测**、**伙伴话题编辑与整理界面改版**、**工作台用户消息气泡对比度优化**及中文“服务商”术语统一。Pi 1.5.0、依赖图、原生组件、会话 JSONL 与 v2 费用账本结构均保持不变。最终冻结源码、归档 SHA256、三平台按需执行及 1.12.0 基线复用记录以 [GitHub Release](https://github.com/YogurtJ/OhMyBuddy/releases/tag/v1.12.1) 附件与[平台验证范围](../RELEASE_INSTALL_VALIDATION.md)为准。

## 自定义服务商一键接入与模型探测

- **一步添加自定义服务商**：在“设置 → 服务商与模型”中，“添加自定义服务商”合并为单一表单。填写服务商名称、接口地址、协议和 API Key 后，可直接点击“获取可用模型”探测远端模型列表，并在同一流程完成保存。
- **分类筛选与安全探测**：探测结果弹窗加宽至 720px，分类胶囊标签自动换行不裁切；按对话模型、图像、视频、语音合成、语音识别与其他分页签展示，默认不勾选，支持搜索与分页加载。上下文窗口、最大输出与视觉/推理能力优先采用服务端返回值，其次参考内置目录。
- **已有自定义服务商直接探测**：已保存的自定义服务商在“添加模型”时可直接复用已保存的 Key 拉取模型列表；探测仅由服务端发起只读 GET 请求，不跟随重定向，API Key 不回传浏览器。
- **术语统一**：中文界面与文档统一使用“服务商”。详见[服务商与模型](../PROVIDER_SETTINGS.md)。

## 伙伴话题界面与工作台消息气泡

- **编辑话题收拢为紧凑单行**：图标槽与话题名称合并为同一行，未设置图标时显示空图标位而非预填表情；辅助说明按需显示，话题指令默认收起，减少弹窗纵向占用。
- **整理话题与二级身份牌**：整理面板改用分段切换、分组标签与带图标的话题列表，仅在勾选话题后显示底部移动栏，分组与回收站行更紧凑；顶部身份牌将当前话题名称移至第二行，正常工作态仅显示状态圆点，避免名字、话题与状态互相挤压。详见[伙伴模式](../BOT_MODE.md)。
- **工作台用户消息气泡**：工作台用户消息气泡改用与伙伴模式一致的主题色淡染底色与边框，随当前主题自动适配，便于与助手回复区分；外部渠道消息保持原样式。

## 安装、升级与验证范围

- **安装与升级兼容**：沿用 1.12.0 的存储布局、Pi 1.5.0 引擎与 v2 费用账本，无需迁移原生会话或账本。完整平台包覆盖 **macOS ARM64（Apple Silicon）、Windows x64、glibc Linux x64**；新 Linux ARM64 完整包继续暂停，历史附件保留原适用范围。详见[安装与恢复](../INSTALL_RECOVERY.md)。
- **按需定向验收与基线复用**：本版涉及服务商设置/模型探测、伙伴话题 UI、工作台气泡样式及对应文案文档。计划在三平台执行受影响的 Node 与 Chromium 测试、准确包探针，以及从正式 1.12.0 的签名更新和恢复验证；未受影响的范围按规则复用 1.12.0 基线。实际执行结果以[平台验证范围](../RELEASE_INSTALL_VALIDATION.md)及发行附件为准。

## English

OhMyBuddy 1.12.1 (with Pi 1.5.0) streamlines custom provider setup with one-step model discovery, redesigns the Buddy topic editor, topic organizer, and two-line identity badge, improves Workspace user message bubble contrast across themes, and standardizes Chinese provider terminology.

Pi 1.5.0, the locked dependency graph, native addons, native session JSONL files, and the v2 usage ledger remain unchanged from 1.12.0. Full platform packages target macOS Apple Silicon, Windows x64, and glibc Linux x64 (new Linux ARM64 packages remain paused). Planned qualification includes targeted Node and Chromium checks, package probes, and signed upgrades and restores from 1.12.0, with unchanged baseline evidence reused by scope. Actual results will be recorded in the release validation report.
