# OhMyBuddy 1.11.1（Pi 1.4.0）

本版已于 2026-10-30 [公开发布](https://github.com/YogurtJ/OhMyBuddy/releases/tag/v1.11.1)，准确归档及验证范围以该 Release 附件为准。1.11.1 修复调度器在异常退出或重启后无法启动的问题，并汇总伙伴头像、话题整理和安装分发方面的改进。Pi 与生产依赖图保持不变。

## 定时任务恢复

调度器原先只检查登记的进程编号是否仍然存在。崩溃、断电或强制结束可能留下旧登记；当系统把相同编号分给其他程序时，调度器会误认为已有实例运行，拒绝启动。感谢 [Matt Abate](https://github.com/mattabate) 在 [#6](https://github.com/YogurtJ/OhMyBuddy/issues/6) 中指出问题并提供清晰的分析和测试建议。

持有者现在由独立 SQLite 连接持有的系统排他锁确定。进程退出后系统自动释放锁，残留记录和 PID 复用不再阻塞启动。已有任务、主线程、运行记录与预算原位保留；中断的执行仍按原规则标为“不确定”，不会因为恢复调度器而自动重跑。

升级前先等待当前工作结束并正常停止旧版本，再启动新版本。不能让采用旧占用判断的版本和新版本共用同一身份并行运行。锁文件可保留，运行期间不要删除或替换。详见[定时任务](../SCHEDULED_TASKS.md)。

## 伙伴形象与话题整理

伙伴形象提供十二款预设和版本化部件组合，可从预设起步、锁定部件搭配、撤销、预览状态并保存。旧头像与配色继续兼容，图片上传保持原流程。等待回复或确认时有独立入口；动作跟随实际工作状态，并尊重浏览器动画偏好与减少动态设置。

话题支持一级分组、搜索、emoji、排序和批量移动。整理界面先选择话题，再选择目标分组；固定底部操作区方便在手机上完成移动。默认查看未分组，全部视图按当前分组排列并显示归属。

话题删除先进入应用内可恢复的回收站。用户另行确认后，才会彻底删除该话题全部原生聊天代际与记事本；仍有任务、学习或媒体工作时拒绝删除，失败不自动重试。普通话题列表只请求正常条目和回收站数量，打开回收站时才读取摘要。升级本身不删除话题或历史。详见[伙伴模式](../BOT_MODE.md)。

## 旧分类与工作台

旧助手分类退出运行流程。原始注册表、身份、会话、正文和书签保留；旧接口明确返回 410，已有入口引导到伙伴或实际工作台线程。伙伴话题与普通身份线程继续使用各自的指令和记忆。

修复收起侧栏时英文 Workspace 标签被截断的问题，统一英文记事本回执名称，并补齐头像预览中待机、睡觉和打招呼状态的英文文案。README 的中英文示例图和动图已更新。

## 完整安装包与更新

本版源码包括 Linux x64/ARM64、Windows x64 和 macOS Apple Silicon 完整包的构建与安装支持。完整包自带独立 Node、Pi、锁定依赖和本地工具，客户端无需运行 npm；更新沿用签名来源校验、停机备份和一次性执行。Windows 包含 Portable Git/Bash 与普通用户安装入口，Linux 使用用户级 systemd，macOS 使用用户 LaunchAgent。

完整安装包使用独立下载渠道和准确构建回执。源码归档与平台安装包分别命名、分别核验，不把已有预览版自动视为包含本次全部修复的新版本；实际可下载版本、平台和签名／公证状态见其分发清单及[完整安装包指南](../FULL_INSTALLERS.md)。

## 升级与验证

源码安装继续使用受支持的 Node 22.x（至少 22.19.0），Pi 保持 1.4.0。升级前保存草稿、停机备份，并保留原生会话及其引用的私有图片对象。不要复用与锁文件不匹配的 node_modules，不改写 JSONL 正文或移动真实数据来冒充升级。

验证按实际变化补验并复用可追溯基线。准确归档、SHA256、本次执行、旧证据复用及未覆盖范围记录在包外验证附件；[平台验证范围](../RELEASE_INSTALL_VALIDATION.md)区分源码准备、本机部署与公开发布。真实模型／微信业务、Safari、实体手机、其他架构和网络文件系统不因本轮合成验证而获得支持声明。

## English

OhMyBuddy 1.11.1 fixes scheduler ownership getting stuck after a crash or reboot when a PID is reused. Ownership now uses an OS-backed SQLite file lock that is released when the process exits. Existing tasks, history and budgets are preserved, and uncertain runs are never replayed automatically. Thanks to Matt Abate for reporting #6 and suggesting a regression test.

The release also adds composable Buddy avatars and improves topic groups, search, bulk moves and recoverable deletion. Legacy assistant categories are retired while their original data remains intact. Source installation and independently distributed full platform packages keep separate manifests and validation records. Stop the previous version before upgrading; do not run old and new schedulers against the same identity. This release was published on October 30, 2026; see the v1.11.1 Release assets for the exact archive and validation scope.
