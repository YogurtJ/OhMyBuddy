# OhMyBuddy 1.14.0-rc.1

这是面向 macOS Apple Silicon、Windows x64 和 glibc Linux x64 的候选版。完整验收结果随实际发布包的校验附件记录。正式版入口和历史结果见[平台验证范围](../RELEASE_INSTALL_VALIDATION.md)。

- Pi 升级至 1.6.0，`undici` 升级至 8.12.4。改进 MCP 工具恢复、扩展重载、RPC 启动事件和中止后的工具结果配对。会话可查看启动诊断、历史思考未被沿用的原因和图片工具状态。详见[原生设置](../NATIVE_SETTINGS.md)。
- 伙伴聊天分叉和复制会在同一伙伴下创建新话题，继承话题指令及分组，保留原草稿和来源定位。符合条件的旧分叉可先预览，再收录为伙伴话题。详见[伙伴模式](../BOT_MODE.md)及[会话工作流](../SESSION_WORKFLOWS.md)。
- 模型配置显示参数来源和渠道价格，未知型号的缺省值为 500k 上下文和 128k 输出。保留渠道限额、已有 Thinking 映射和历史账单。推理专用型号的探测使用受支持的思考等级。官方 GPT-6.2 Sol／Astra 支持 Fast 和 Ultrafast。详见[服务商设置](../PROVIDER_SETTINGS.md)。
- HTML 预览中的章节锚点在预览内部跳转。取消成果读取、搜索、文件浏览或目录选择时，维护占用在实际资源清理后释放。

升级前保存草稿并使用应用的停机备份。恢复时遵循[安装与恢复](../INSTALL_RECOVERY.md)。

## English

This release candidate integrates Pi 1.6.0, runtime notices, Buddy forks as topics, and improvements to model metadata, pricing, and reasoning compatibility. It fixes anchor navigation inside HTML previews and maintenance admission after cancelled requests. The target packages are macOS Apple Silicon, Windows x64, and glibc Linux x64. The final verification record will bind results to package checksums.
