# OhMyBuddy 1.13.0（Pi 1.5.2，发布准备）

本版汇总 **Pi 1.5.2 接入**、**缓存保温与完整费用统计**、**伙伴统一记事本**、**头像编辑器**、Mermaid 修复与任务目录安全清理。功能已在 macOS 本机启用；正在准备 macOS ARM64、Windows x64 和 glibc Linux x64 发行候选，尚未公开发布。当前正式版仍为 [1.12.2](1.12.2.md)，准确包 SHA256、实机结果和原失败将在包外验收附件中记录。

## Pi 1.5.2 与提示缓存

- 发布验收补充修正全局退出的 worker 清理时限，以及调度器首次并发启动的 SQLite 瞬时读锁竞争；单一调度持有者和强制退出错误继续保留。这两项修正尚未随当前本机载荷启用。
- 八个 Pi 包统一锁定 1.5.2，MCP 命名使用公共入口，保留工具名称、冲突身份和子 Agent 授权。正常关闭通过原生 stdin EOF 等待异步清理与凭据落盘；超时强制退出明确报告失败。
- “设置 → Pi 配置 → 上下文”新增全局提示缓存保温，可选关闭、仅运行中和空闲时也保持。未配置时继续沿用 `streaming`；空闲保温需要明确选择，由 Pi 决定请求时机和经济性，最长 30 分钟。会话详情展示当前模式与状态。详见 [Pi 原生设置](../NATIVE_SETTINGS.md)。
- 用量统计补计原生保温请求，单列已经包含在总费用中的保温金额与次数。账本从 v2 追加列升级至 v3，重新核对现存历史补录遗漏，保留已入账事实和去重。供应商实报金额继续优先，保温费用不会再次叠加。详见[用量统计](../USAGE.md)。
- 模型兼容参数按 Pi schema 投影，包括 `requiresToolsWithToolHistory`、`requiresNonNullAssistantContent`、`promptCacheKeyMode` 与 Anthropic `supportsMessageThreads`。第三方代理须按实际能力配置，不能仅因使用 Anthropic 协议就假定支持 threads。

## 伙伴记事本、头像与图表

- “我记着的事”改为主聊天和所有话题共用的记事本；任意聊天可查询、更新、核对来源原文，跨聊天完成同步取消待跟进提醒。桌面和手机界面提供待跟进、约定与资料、已结束、搜索和相关事情筛选。忙碌时可编辑，冲突保留草稿；归档或删除来源聊天保留已保存事项和引文。旧事项保留状态、日期与出处接入，原聊天不改写。详见[伙伴模式](../BOT_MODE.md)。
- 头像预设增至二十四款，加入明暗、高光、肢体和状态特效。“自己搭”提供可视化部件、锁定搭配、撤销与动作预览，活动头像响应指针和按下动作，动画开关可关闭动作。保留旧预设、原版配色及版本 1 的组合格式。
- 修复 Safari/WebKit 下 Mermaid 沙箱脚本加载问题；流式回复保留已绘制图表、失败提示与源码展开状态，减少重绘闪动。隔离、清理和渲染限额保持。详见 [Mermaid](../MERMAID.md)。
- 修复跨机器迁移伙伴身份后既有技能误报重名的问题；确认规范路径与修订后保留技能 ID、历史及撤销回执，继续拒绝真实冲突和外部修改。详见[档案记忆](../PROFILE_MEMORY.md)。

## 任务目录与升级恢复

- 加固任务工作目录清理，协调新建、分叉、导入、移动和运行启动，保护子目录会话，绑定目录身份与确认版本。不能完整核对时保留；回收前暂存，失败显示实际恢复位置，超时或身份变化明确报告待核对。操作记录持久化，响应丢失只查询，不重放。macOS 使用系统回收站，Linux 使用 `gio`；无安全回收能力的平台保留非空目录。详见[会话工作流](../SESSION_WORKFLOWS.md)。
- 升级前保存草稿、停止冲突工作并做停机备份；保留原生会话、外置图片、媒体和配置路径。原生 JSONL 无需迁移，账本 v3 采用追加升级；若需回退旧程序，须配套升级前的停机备份，不能让旧版直接接管升级后的账本。新服务受理请求后，不自动用旧数据回退。详见[安装与恢复](../INSTALL_RECOVERY.md)。
- 本轮目标为 macOS Apple Silicon、Windows x64、glibc Linux x64。新 Linux ARM64 完整包继续暂停。各平台需要准确包的 Node／Chromium、安装、1.12.2 升级、正常停机与原路径恢复证据；本页的准备状态不表示已经通过。

## English

OhMyBuddy 1.13.0 integrates Pi 1.5.2, configurable prompt-cache warming with complete warming usage accounting, a shared Buddy notebook across main chat and topics, a redesigned avatar editor, Mermaid fixes, and stronger task workspace cleanup. Existing installations retain streaming-only cache warming unless idle warming is explicitly selected. The usage ledger receives additive v3 columns and a deduplicated historical rescan; native session JSONL files do not require migration.

This version is being prepared for macOS Apple Silicon, Windows x64, and glibc Linux x64. Native package qualification, upgrades from 1.12.2, graceful shutdown, and same-path backup restores are pending their artifact-bound receipts. This is not a public release announcement. New Linux ARM64 packages remain paused. Synthetic tests do not establish real paid-provider/OAuth operation, physical mobile device coverage, or OS signing and first-open approval.
