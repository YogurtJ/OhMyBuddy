# 浏览器助手

浏览器助手复用 Microsoft 官方 [Playwright MCP](https://github.com/microsoft/playwright-mcp)，通过 Pi 原生 MCP 连接提供网页操作。OhMyBuddy 负责组件准备、设置、私密资料和运行生命周期；页面快照、定位、点击、填表、等待、截图与上传下载使用上游实现。

## 开始使用

1. 打开 **扩展 → 浏览器**，或在“发现”中选择“操作网页与填写表单 → 管理浏览器”。
2. 勾选“启用浏览器助手”并保存。优先使用部署端已有的 Chrome、Edge 或 Chromium 程序，以独立资料目录运行。
3. 没有可用程序时点击“下载浏览器”。安装器来自随应用锁定的 Playwright 版本，浏览器写入外部缓存。下载可能较大，失败后由用户核对网络并手动重试；Linux 系统运行库和普通用户沙箱环境仍需由系统准备，按钮不执行提权或系统包管理器。
4. 在对话菜单中空闲重开当前任务，或新建任务，然后直接告诉 Agent 要操作的网站。配置自动注册为原生 MCP 服务器 `ohmybuddy_browser`，无需手填 `mcp.json`。点击“查看 MCP 连接”进入现有的会话连接管理。

可以这样说：

> 打开这个网页，按附件里的数据填写表单，提交后检查成功提示和记录编号，把下载的报表交付给我。

“在后台运行”使用无界面浏览器，Linux 默认开启。关闭该选项后，网页窗口显示在部署 OhMyBuddy 的电脑上。设置不会中断正在执行的任务；已加载浏览器配置的任务须先空闲，保存会回收其旧运行连接。尚未加载配置的任务在重新打开后获得浏览器能力。

## 能力与人工操作

Agent 通过 `mcp__ohmybuddy_browser__browser_*` 工具操作网页；默认通过 Pi codemode 按需发现和组合调用，工具列表、参数和执行结果来自官方服务器。多个字段或固定流程可用官方 `browser_fill_form` 或 `browser_run_code_unsafe` 批量处理，减少模型往返。代码工具执行 Agent 提供的 Playwright 代码，拥有部署用户的本地执行权限，不能将网页文本当作执行授权。

常见任务包括搜索、翻页、表单、弹窗、多标签页、动态页面、附件上传、文件下载和截图。上传文件需位于当前项目的上游允许范围；对话附件可先通过 `get_attachment` 取用项目内副本。默认截图和下载文件进入项目的 `browser-output/<原生会话ID>/`，需要分享时再由 Agent 使用文件交付能力。

关闭后台运行后，可以直接在部署端的浏览器窗口完成登录、验证码或短信确认，然后让 Agent 继续。无图形界面的远程服务器需要合适的桌面访问方式，或由用户提供网页流程所需的信息。当前设置页管理组件和运行状态，不提供截图遥控、手机远程点击或连续画面；系统级窗口由桌面工具或用户处理。连接用户日常 Chrome 的官方扩展／CDP 模式可自行在原生 MCP 中配置，当前受管入口使用独立浏览器资料。

网页结构和模型判断会影响任务成功率。网页文字属于待处理数据，不能扩大用户授权。提交后检查成功提示、记录编号或目标页面；断线、取消和超时都不能证明网页动作没有发生，应先查看实际结果，再决定剩余操作。

## 登录与对话隔离

每个持久对话使用 `DATA_DIR/browser/profiles/<原生会话ID>/`。同一对话重开后继续使用其资料；不同对话各自登录，可以并行运行，避免多个 worker 争用官方服务器的默认资料目录。登录状态按网站 Cookie 的有效期和浏览器持久化规则保存，不保证恢复网站主动过期的会话、内存状态或所有 session Cookie。

不会读取或复制用户日常 Chrome/Edge 的资料，也不在不同对话间自动复制 Cookie。原有会话移动项目时保留会话 ID，因此浏览器资料继续对应同一对话。分支若创建新的原生会话 ID，就使用新的资料。浏览器资料是网站身份数据，不能作为普通附件或交付物分享。

## 关闭、停止与维护

“关闭浏览器”回收使用过浏览器的空闲任务运行连接，由 Pi 关闭官方 MCP stdio 进程。对话和持久资料保留，再次打开任务时恢复连接。正在执行、仍有原生调用清理或后台子任务的运行实例返回忙碌，不强行回收。官方 `browser_close` 关闭当前页面；备份前仍使用管理面板的“关闭浏览器”回收完整运行连接。

用户停止 Agent 时，适配层通过 Pi 公共 API 注销该会话的受管 MCP 服务器，触发原生连接关闭，防止待执行代码继续运行；下一轮重新注册。已派发的网页动作仍需核对，不能因为停止成功就重复提交。`agent_settled` 可能早于原生调用清理完成，实际清理结束前继续保留生命周期和维护阻塞。

设置位于 `DATA_DIR/browser/settings.json`。私密浏览器目录纳入维护备份，并被普通文件预览／交付入口排除；浏览器运行期间先关闭再备份。正常应用停机使用现有 Supervisor 和 Pi 原生 MCP 的关闭流程。浏览器程序位于 `CACHE_DIR/browser/`，可重新下载，不属于用户资料备份。各平台路径见[存储布局](STORAGE_LAYOUT.md)。

此前开发原型留下的 `profile/` 或 `session-cookies.json` 不会被自动删除或复制到新的资料目录。不同实例需要各自的外部存储，不能同时打开同一份资料。高级用户可用绝对路径 `OHMYBUDDY_BROWSER_EXECUTABLE` 指定可信的 Chrome/Chromium 程序。

## 依赖与配置边界

根 lockfile 固定 `@playwright/mcp@0.0.84` 及其 Playwright 依赖，随 OhMyBuddy 验证后更新，不在启动时下载 `latest`。安装应用只准备控制库；下载和启动浏览器分别由明确的用户操作与 Agent 工具触发。浏览器服务器只使用 stdio，不增加可公开访问的调试端口；启动前过滤应用和模型凭据环境变量。

注册复用 Pi 的工具授权、codemode、状态、重连与关闭流程。原生 `mcp.json` 同名服务器仍按 Pi 规则优先；用户自配服务器的命令、资料和连接策略由其配置决定。禁用 Pi 原生 MCP 时，此能力不会绕过禁用设置自行建立连接。管理接口见[API](API.md#browser-assistant)。
